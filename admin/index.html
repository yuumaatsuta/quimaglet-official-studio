GitHub につなぐ

内容は GitHub のリポジトリ（public/content.json）に保存され、サイトに 1〜2 分で反映されます。
使うのは「Fine-grained personal access token」です。GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で、Repository access をこのサイトのリポジトリだけにし、 Permissions の Contents を「Read and write」にして作ってください。

About

About を開くと、部屋の上にノイズ混じりで文字が映ります。本文とまわりの言葉は同じ書体で組まれ、本文がまわりに溶け込みます。

News（お知らせ）

いちばん上のお知らせが、部屋の奥の壁にロボットが映す「最新のお知らせ」になります。本文の URL はリンクになります。

Works

Goods（グッズ）

Goods を選ぶと、ロボットがこの内容を古い紙のメニューにして、目の前まで持ってきます（手書きの字で、2 列に並べます。たくさんあるときは、スクロールすると巻物を巻き取りながら下の続きが見えます）。グッズの展開状況を 1 点ずつ並べます。購入ページの URL を入れると、紙の「ONLINE STORE」から開けます。状況の言葉で色が変わります（販売中＝緑、予約受付中＝青、準備中・近日＝黄、売り切れ・完売＝赤）。上にあるものから順に表示されます。
